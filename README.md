android-apidemos
================

> **This repository has moved.** Development now continues in the [appium-android monorepo](https://github.com/appium/appium-android/tree/main/packages/android-apidemos).

A fork of Google's Android ApiDemos application, used for testing Appium

#### Requirements

- Java 17
- Node.js (npm)

#### Building

> npm run build
